How it works

Enter the email address of an existing Roomi account that you want to make an admin. This account will gain access to the admin panel where they can manage users, matches, and system data.

Security Notice

Only grant admin access to trusted users. Admins can view all user data, delete accounts, and manage matches. For security, this page should be disabled in production.
